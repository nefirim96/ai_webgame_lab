# 게임 팩 (game)

## 기본 정보

- 이름: game
- 설명: 웹게임 기획과 구현 요청을 구조 지도로 나눠서, 수정 프롬프트 하나로 반영할 수 있게 한다.
- 적용 대상: 브라우저에서 실행하는 HTML과 JavaScript 게임 (예: 타워디펜스, 퍼즐, 슈팅)

## 노드 단위

- 기획 문서는 기능 단위로 나눈다. 예: 웨이브 규칙, 타워 스펙, 적 스펙, 수치 조정표
- 구현 파일은 역할 단위로 나눈다. 예: 게임 루프, 타워 로직, 적 로직, 화면
- 수치는 수치 조정표 한 곳에서만 관리한다. 다른 문서는 그 표를 참조한다.

## 참조 스킬

이 팩은 아래 스킬을 참조합니다. 스킬 내용을 이 팩에 복사하지 않습니다.

- `web-game-studio`: 기획, 코드 작성, 화면 디자인, 배포 단계에서 사용
  - 설치되어 있으면 해당 스킬의 지침을 따릅니다.
  - 설치되어 있지 않으면 사용자에게 기획 질문을 직접 받아 진행합니다.

## 진행 순서

1. 요청을 기획 문서로 정리한다 (docs/).
2. 기획 문서를 기준으로 구현 파일을 만든다 (src/).
3. 지도 파일을 만들거나 갱신한다 (.claude-studio/).
4. 사용자가 지도에서 수정 요청을 고르면, 요청된 파일만 고친다.

## 완료 기준

- `src/index.html`을 브라우저로 열었을 때 기본 동작이 된다.
- 사용자가 요청에서 정한 검증 항목을 통과한다.
- `.claude-studio/history/`에 버전 기록이 남아 있다.

## 포함 파일

- `pack.md`: 이 문서
- `templates/request.md`: 수정 요청 템플릿
