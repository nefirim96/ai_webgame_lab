# ai_webgame_lab · Skill Studio

Claude에게 요청을 맡길 때, 바로 실행하지 않고 **구조 지도**에서 고칠 부분을 먼저 고르게 해 주는 스킬입니다.

> 상태: v0 (비공개 테스트 중)

## 무엇을 해 주나

- 게임, 릴스, 업무 문서처럼 분야가 달라도 같은 5단계 흐름으로 진행합니다.
- 작업 결과를 파일 단위 블록으로 나눈 지도(HTML)로 보여 줍니다.
- 블록을 클릭해 수정 요청을 쌓고, 한 번에 붙여넣을 프롬프트를 만듭니다.
- 수정할 때마다 버전(v0, v1 …)과 변경 기록을 남깁니다.

## 설치

개인 스킬로 쓰기:

```
~/.claude/skills/skill-studio/
```

프로젝트 안에서만 쓰기:

```
<프로젝트>/.claude/skills/skill-studio/
```

폴더를 통째로 복사하면 됩니다. 설치 후 Claude에게 "게임 만들고 싶어"처럼 요청하면 스킬이 동작합니다.

## 구성

```
SKILL.md              스킬 본문 (흐름과 규칙)
templates/
  map.html            구조 지도 화면 (단일 파일, 외부 호출 없음)
  map-data.js         지도 데이터 예시
```

## 보안

- 팩과 템플릿은 마크다운과 텍스트만 사용합니다. 실행 스크립트를 넣지 않습니다.
- 지도 화면은 인터넷 연결 없이 동작합니다.
- 비밀값(토큰, 비밀번호)은 어떤 파일에도 저장하지 않습니다.
